## P0-001 — OrderConfirmation `$NaN`

### Root Cause
O backend retorna os itens do pedido com campo `unitPrice`, mas o frontend esperava `price`. Quando `item.price` é `undefined`, a expressão `(undefined + optsTotal) * quantity` resulta em `NaN`, que é renderizado pelo componente `Price`.

### Contrato da API confirmado
`GET /api/orders/:id` retorna itens com:
- `id`
- `orderId`
- `menuItemId`
- `name`
- `quantity`
- `unitPrice`
- `subtotal`
- `comment`
- `options`

`price` **não existe** na resposta.

### Fix
`packages/storefront/src/pages/OrderConfirmation.tsx`:
- Atualizado tipo `OrderItem` para incluir `unitPrice?: number`, `subtotal?: number`, `price?: number`.
- Substituição do cálculo que usava `item.price` por lógica que:
  1. Usa `item.unitPrice` se existir.
  2. Fallback para `item.price`.
  3. Se ambos ausentes e `subtotal`/`quantity` presentes, calcula `subtotal / quantity`.
  4. Se ainda ausente, loga `console.error` e renderiza `—` em vermelho, sem mascarar com `$0.00`.

### E2E
Arquivo: `packages/storefront/e2e/p0-checkout.spec.ts`
- Teste `P0-001: OrderConfirmation item price is not NaN`
- Cria pedido real em dev, verifica redirect para `/order/:id` e garante que o corpo da página não contém `$NaN`, `NaN` ou `undefined`.
- **PASS**

## P0-002 — Checkout Delivery sem inline errors

### Root Cause
`validateAddress()` em `Checkout.tsx` apenas retornava `boolean` baseado no preenchimento dos campos, mas nunca populava `addressErrors`. A única indicação era um erro global (`setError(...)`). Portanto, os inputs de endereço não exibiam mensagens inline.

### Fix
`packages/storefront/src/pages/Checkout.tsx`:
- Adicionado estado `addressErrors` (`{ line1, city, state, zip }`).
- `validateAddress()` agora preenche `addressErrors` com mensagens específicas por campo.
- Criada função `updateAddress(field, value)` que atualiza o campo e limpa o erro correspondente.
- Todos os inputs de endereço usam `updateAddress` e recebem `error={addressErrors.<field>}` + `errorTestId`.
- Adicionadas chaves i18n em todos os locales (`addressLine1Required`, `cityRequired`, `stateRequired`, `zipCodeRequired`).

### E2E
- Teste `P0-002: Delivery without address shows inline per-field errors`
- Seleciona Delivery, limpa endereço, clica em submit e verifica `address-line1-error`, `address-city-error`, `address-state-error`, `address-zip-error`.
- **PASS**
